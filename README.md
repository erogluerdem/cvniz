# 🚀 CVniz: Yapay Zeka Destekli Uçtan Uca Kariyer & CV SaaS Platformu

**Tam Açık Kaynak Topluluk Sürümü**  
Geliştirici: **Erdem Eroğlu** ([erdemeroglu.com.tr](https://erdemeroglu.com.tr))

CVniz sıradan bir CV hazırlama aracı değildir. Modern yapay zeka entegrasyonlarını (OpenAI & Gemini) kullanarak özgeçmiş oluşturmanın her adımına akıl katan, mülakatlara hazırlayan ve iş bulma sürecinizi yöneten tam donanımlı bir akıllı kariyer asistanıdır.

## ✨ Benzersiz Yapay Zeka (AI) Yetenekleri

*   🪄 **AI Smart Fill (Tek Tıkla CV Doldurma):** Hedeflediğiniz pozisyonu (örn: "Frontend Geliştirici") yazın; yapay zeka profesyonel özetinizi, teknik becerilerinizi ve iş deneyimlerinizi saniyeler içinde sizin için doldursun.
*   📸 **AI Headshot (Stüdyo Kalitesinde Fotoğraf Üretici):** Evde çektiğiniz sıradan bir selfie'yi saniyeler içinde takım elbiseli, ofis veya stüdyo arka planlı profesyonel bir vesikalık fotoğrafa dönüştürün.
*   📈 **AI LinkedIn Profile Optimizer:** CV'nizi analiz ederek LinkedIn başlığınızı (Headline) ve "Hakkında" yazınızı en üst sıralara taşıyacak şekilde optimize eder.
*   🏗️ **AI Project Writer:** Projelerinizi ve kullandığınız teknolojileri STAR metodolojisine göre detaylandırarak, teknik derinliği yüksek, etkileyici açıklamalar üretir.
*   ✉️ **AI Reference & Cover Letter:** Başvurduğunuz şirkete ve pozisyona özel, son derece profesyonel ön yazılar ve referans mektupları hazırlar.

## 🎭 İnteraktif Kariyer ve Mülakat Simülasyonları

*   🧠 **Interview Coach Pro (Canlı Mülakat Koçu):** Hedef pozisyonunuza uygun zorlu sorularla gerçek zamanlı (sesli/yazılı) mülakat simülasyonu yapar, beden dili, ses tonu ve teknik doğruluk üzerine detaylı bir karne sunar.
*   💬 **Salary Negotiator (Maaş Pazarlığı Simülatörü):** Zorlu bir İK yöneticisi botuyla maaş pazarlığı rol yapma oyunu oynayın. Değer önerinizi sunarak İK'nın teklifini yükseltmeye çalışın!
*   🎯 **Skills Gap Analyzer (Beceri Açığı Analizi):** CV'niz ile başvurduğunuz iş ilanını karşılaştırıp, eksik anahtar kelimeleri ve öğrenmeniz gereken teknolojileri analiz eder.

## 🛠️ Gelişmiş Editör ve Entegrasyon Teknolojileri

*   📊 **Real-Time ATS Scanner:** CV'nizi İK yazılımlarının (ATS) gözünden analiz eder; okunabilirlik skoru, format uyumu ve anahtar kelime yoğunluğunu editörde yazarken anlık gösterir.
*   🌐 **Live Share & Multiplayer (Canlı İşbirliği):** Google Docs tarzında, CV'nizi kariyer danışmanınız veya arkadaşlarınızla canlı paylaşıp aynı anda düzenleyin.
*   🔄 **Multi-Format Import (LinkedIn & GitHub):** LinkedIn profilinizi tek tıkla CV'ye dönüştürün. GitHub entegrasyonuyla tüm projelerinizi, repolarınızı ve dillerinizi anında aktarın.

## 🏗️ Mimari ve Kullanılan Teknolojiler

Bu platform, ölçeklenebilir ve modern bir teknoloji yığını ile geliştirilmiştir:

*   **Web Frontend:** React 18, Vite, Tailwind CSS, Framer Motion, Lucide Icons
*   **Mobil Uygulama:** React Native (Expo SDK) — iOS & Android
*   **Backend:** Node.js, Express.js
*   **Veritabanı:** MongoDB (Mongoose), Redis Caching
*   **Yapay Zeka:** OpenAI API & Google Gemini API
*   **İş Zekası (BI):** Churn Tahmini, ARIMA Gelir Öngörüsü, K-Means Segmentasyonu
*   **Altyapı:** Docker & Docker Compose

## 📖 Kurulum ve Hızlı Başlangıç

Adım adım kurulum, ortam değişkenleri ve detaylı rehber için lütfen **[KURULUM_VE_TESEKKURLER.md](./KURULUM_VE_TESEKKURLER.md)** dosyasını inceleyin.

**Docker ile Hızlı Başlangıç:**
```bash
# Repo'yu klonlayın ve klasöre girin
git clone https://github.com/erogluerdem/cv.git
cd CV

# Çevre değişkenlerini kopyalayın
cp .env.example .env

# Konteynerları arka planda ayağa kaldırın
docker-compose up -d --build
```
