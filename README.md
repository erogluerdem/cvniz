# 🚀 CVniz — Yapay Zeka Destekli Uçtan Uca Kariyer & CV SaaS Platformu

> **Tam Açık Kaynak Topluluk Sürümü**  
> Geliştirici: **Erdem Eroğlu** ([erdemeroglu.com.tr](https://erdemeroglu.com.tr))

CVniz; modern yapay zeka entegrasyonları (OpenAI & Gemini), stüdyo kalitesinde vesikalık fotoğraf dönüştürme (AI Headshot), canlı mülakat koçluğu (Interview Coach Pro), maaş pazarlığı simülasyonu, gerçek zamanlı ATS tarayıcı, Google Docs tarzı canlı işbirliği editörü, React Native (Expo) mobil uygulaması ve makine öğrenmesi destekli BI paneliyle eksiksiz bir SaaS platformudur.

---

## 📖 Kurulum ve Teşekkür Kılavuzu

Adım adım kurulum, ortam değişkenleri ve detaylı rehber için lütfen **[KURULUM_VE_TESEKKURLER.md](./KURULUM_VE_TESEKKURLER.md)** dosyasını inceleyin.

### Hızlı Başlangıç (Docker):
```bash
cp .env.example .env
docker-compose up -d --build
```

---

## 🛠️ Mimari ve Teknolojiler

* **Web:** React 18, Vite, Tailwind CSS, Framer Motion, Lucide Icons
* **Mobil:** React Native (Expo SDK) — iOS & Android
* **Backend:** Node.js, Express.js, MongoDB (Mongoose), Redis Caching
* **Yapay Zeka:** OpenAI API & Google Gemini API
* **İş Zekası:** Churn Tahmini, ARIMA Gelir Öngörüsü, K-Means Segmentasyonu
* **Konteyner:** Docker & Docker Compose
